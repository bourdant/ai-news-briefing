클로드 오퍼스 5.5 vs GPT-6 솔·루나, 하루 만에 동시 출시

🆕 신규 발표 · 공식 발표 · 3곳에서 확인

챗GPT를 만든 오픈AI와 AI 안전 연구로 유명한 앤트로픽이 22일(현지시간) 하루 사이에 나란히 새 모델을 내놨어. 앤트로픽은 복잡한 추론과 코딩에서 최고 성능을 낸다는 '클로드 오퍼스 5.5'를 공개하며, 실제 운영 비용을 이전 모델보다 40% 낮췄다고 밝혔어. 곧바로 오픈AI도 맞불을 놓듯 'GPT-6 솔'과 '루나'를 내놓으며 API 이용료를 기존 프로모션가 대비 절반 이하로 낮췄지. 평가 기관 아티피셜 애널리시스 기준 오퍼스 5.5는 지능 지수 1위에 올랐고, 두 회사 모두 '최고 성능'보다 '비용 효율'을 앞세운 게 특징이야.

옆집 카페 두 곳이 같은 날 신메뉴를 내면서 동시에 가격까지 내린 셈인데, 개발자들 입장에선 최고의 시즌이지. 모델 경쟁이 '누가 더 세냐'에서 '누가 더 싸게 세게 주냐'로 넘어갔다는 신호고, API 요금 전쟁은 앞으로 더 치열해질 듯. 같은 날 발표한 거, 우연이라기엔 타이밍이 너무 절묘한데 — 우연 아니지ㅋㅋ 서로 눈치 보다가 동시에 카드 던진 거지.

📊 앤트로픽은 오퍼스 5.5의 40% 비용 절감을 '이전 모델(오퍼스 5) 대비 실제 운영 비용' 기준으로, 오픈AI는 GPT-6 솔·루나의 가격 인하를 'GPT-5.6 프로모션 가격 대비 API 단가' 기준으로 제시해 비교 기준이 서로 다름.

메타 '뮤즈' 돌풍에 주가 급등, 아마존은 쇼핑 접근 차단

💼 비즈니스 · 2곳에서 확인

페이스북·인스타그램을 운영하는 메타가 지난 8일 내놓은 개인 맞춤형 AI 에이전트 '뮤즈'가 출시 2주 만인 23일 미국·캐나다 애플·구글 앱스토어 무료 다운로드 1위에 올랐어. 센서타워 집계로 누적 다운로드 280만 건, 첫 10일 일평균 증가율 55%로 챗GPT의 초기 흥행 기록도 넘어섰지. 흥행 여파로 메타 주가는 한 주 만에 약 13% 급등했어. 그런데 정작 아마존은 뮤즈가 아마존닷컴에서 대신 쇼핑하지 못하도록 접근을 차단해버렸어. 이용자 동의 없이 에이전트가 계정을 대신 조작하는 게 약관 위반이라는 이유야.

편의점 알바생(에이전트)이 손님 대신 옆 마트에서 장까지 봐주겠다고 나섰는데, 마트 사장이 '내 매장 CCTV로 맘대로 카트 끌고 다니지 마'라고 막아선 그림이야. AI 에이전트가 실생활 서비스로 넘어오면서 플랫폼 간 '내 데이터·매장에 누구 맘대로 들어오냐' 전쟁이 본격화된 거지. 앞으로 이커머스마다 비슷한 차단 조치가 도미노처럼 이어질 가능성 높아. 흥행은 흥행이고 전쟁은 전쟁이네ㅋㅋ 인기 얻자마자 사방에서 문 걸어 잠그는 거 보면.

구글 '제미나이 4', 출시 임박 정황 포착

🆕 신규 발표 · 2곳에서 확인

구글 AI 연구조직 딥마인드의 코레이 카부코글루 수석부사장이 더인포메이션 인터뷰에서, 차세대 모델 '제미나이 4'가 현재 사후 학습(모델을 다듬는 마지막 단계) 초기 단계이며 연말보다 훨씬 앞당겨 출시하고 싶다고 밝혔어. 비슷한 시점 AI타임스는 내부 코드명 '아르곤'으로 불리는 제미나이 4 프로의 초기 체크포인트가 벤치마크 플랫폼에서 '제미나이 3.8 플래시'로 위장된 채 테스트되고 있다고 보도했지. 유출된 결과물은 그동안 약점으로 꼽힌 UI·웹 디자인 생성 능력이 크게 개선됐다는 평가를 받고 있어.

경쟁사들이 신제품을 속속 내놓는 와중에 구글만 시즌 내내 예고편만 틀던 참이었는데, 이번엔 진짜 출시일이 코앞으로 당겨질 조짐이야. 신메뉴 이름 숨기려고 포장지만 바꿔 시식 나눠준 건데 손님들이 다 눈치챈 셈이지ㅋㅋ 오퍼스 5.5, GPT-6가 이미 나온 마당에 구글까지 가세하면 '프론티어 모델 가을 대전'이 완성되는 건데, 진짜 볼만하겠어.
